# Project Documentation

This folder contains the engineering and design documentation for our EXSU 620 NG tube pH verification prototype.

It will include:
- **Engineering requirements** — Quantitative requirements and acceptance criteria.
- **System design** — Architecture, sensing approach, alarm logic, and design rationale.
- **System diagrams** — Block diagram, wiring diagram, alarm state chart, and sequence diagram.
- **Risk analysis** — Potential hardware, software, and operational failures with proposed mitigations.
- **Traceability matrix** — Links between engineering requirements, design decisions, and verification results.
- **Final design dossier** — Complete PDF report documenting the prototype's design, implementation, testing, and limitations.

**Note:** This prototype is intended for educational, bench-top testing only and is not approved for clinical use.
