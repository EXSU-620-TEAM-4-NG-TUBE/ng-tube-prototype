# Hardware

This folder contains the hardware design and assembly documentation for our EXSU 620 NG tube pH verification prototype.

It will include:
- **Wiring diagram** — Connections between the Raspberry Pi Pico 2 W, pH sensor, NeoPixel LED ring, and button.
- **Component and interface table** — Hardware components, pin assignments, signal types, and operating voltages.
- **Assembly photographs** — Images of the assembled prototype.
- **3D enclosure files** — STL files used to print the prototype's enclosure.
- **CAD files** — Editable design files or a link to the original CAD model.

The prototype includes a pH electrode, an electronics enclosure, a probe holder, and a sample cup.

**Note:** This hardware is intended for educational, bench-top testing only and is not approved for clinical use.
