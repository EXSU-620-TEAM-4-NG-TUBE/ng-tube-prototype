# Verification

This folder contains the experimental verification records and results for our EXSU 620 NG tube pH verification prototype.

It will include:
- **Verification plan** — Test procedures, acceptance criteria, and pass/fail requirements.
- **Calibration records** — Reference buffer measurements and calibration coefficients.
- **Raw data and logs** — Selected experimental readings and system outputs.
- **Analysis and plots** — Calibration accuracy, stability, settling time, and drift.
- **Verification results** — Documented pass/fail outcomes for each engineering requirement.
- **Functional testing evidence** — Results for LED indicators, audio alarms, button operation, sensor faults, and phone notifications.

Verification records will distinguish completed tests, failed tests, and tests requiring further evaluation.

**Note:** This prototype is intended for educational, bench-top testing only and is not approved for clinical use.
