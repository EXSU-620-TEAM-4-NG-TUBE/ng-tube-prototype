# Database

This folder contains the database files and documentation for our EXSU 620 NG tube pH verification prototype.

It will include:
- Database schema defining how test results and calibration records are stored.
- An anonymized example database or instructions for generating sample data.
- Documentation explaining the fields recorded for each test, including sample ID, operator initials, pH measurement, test verdict, calibration status, timestamps, and acknowledgement status.

The database supports test history, record keeping, and verification of prototype performance.

**Note:** This prototype is intended for educational, bench-top testing only and is not approved for clinical use.
