# Windows monitoring software

Start the browser monitor with [start_browser_monitor.cmd](start_browser_monitor.cmd). See the [browser monitor guide](browser_monitor/README.md) for setup and consent. The legacy desktop monitor is [laptop_monitor_stop.py](laptop_monitor_stop.py).

[Saved bench logs](../database/README.md) and [verification tests](../verification/tests/README.md) are stored alongside the software folder.
