# Software Tests

This folder contains the software tests used to evaluate our EXSU 620 NG tube pH verification prototype.

It will include:
- **Simulated tests** — Tests using predefined inputs to verify pH calculations, decision thresholds, and alarm behavior.
- **Physical tests** — Tests performed using the assembled prototype and reference pH buffer solutions.
- **Test instructions** — Procedures for running each test and interpreting the results.
- **Fault detection tests** — Tests evaluating how the system responds to invalid, unstable, or drifting sensor readings.

Simulated software tests and physical verification tests are documented separately to distinguish expected software behavior from experimentally demonstrated performance.

**Note:** This prototype is intended for educational, bench-top testing only and is not approved for clinical use.
